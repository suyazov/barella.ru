# Как редактировать список объектов и страницы отдельных объектов

## Список объектов

1. Откройте WordPress → Страницы → «Объекты» → «Редактировать в Elementor».
2. Для заголовка или названия объекта выберите нужный заголовок и измените поле «Заголовок».
3. Для описания выберите текстовый виджет и измените его текст. Вставляйте текст без чужого форматирования.
4. Для замены фотографии выберите изображение → «Выбрать изображение» → медиатека.
5. Перед сохранением проверьте страницу в режимах компьютера и телефона, затем нажмите «Обновить» / «Опубликовать».

В структуре страницы карточки подписаны «Объект 1» … «Объект 10», а их поля — «название», «описание», «фотография», «ссылка». Оформление хранится отдельно в HTML-виджете «Оформление каталога». Для обычных изменений текста и фото этот виджет открывать не нужно.

Редактируйте страницу через Elementor: стандартный редактор WordPress не показывает её отдельные виджеты. При случайном удалении блока используйте историю Elementor и восстановите предыдущую версию.

## Фотографии на странице отдельного объекта

1. Откройте нужную страницу объекта → «Редактировать в Elementor».
2. Выберите блок с фотографиями. В структуре страницы он называется «Фотографии объекта — добавить и удалить фото».
3. Нажмите миниатюры в панели галереи. В открывшемся окне выберите «Добавить в галерею». Выберите фотографии из «Библиотеки файлов» или откройте «Загрузить файлы», чтобы загрузить новые.
4. Нажмите «Добавить в галерею», затем «Вставить галерею» в окне медиатеки.
5. Чтобы удалить снимок или изменить порядок, нажмите миниатюры в панели галереи. Удалите нужный снимок из галереи или перетащите фотографии в нужном порядке; подтвердите обновление. Удаление из галереи не удаляет файл из медиатеки.
6. Проверьте режимы компьютера и телефона, затем сохраните страницу кнопкой «Обновить» / «Опубликовать».

Заголовок, адрес, заказчик, предмет работ и список выполненных работ также редактируются отдельными виджетами Elementor. Фотографии не нужно вставлять в текстовый редактор. Размеры снимков и число колонок задаёт оформление: три колонки на компьютере, две на планшете и одна на телефоне.

Оформление находится в отдельном HTML-виджете «Оформление объекта». Для изменения текста и фотографий его открывать не нужно. Перед сохранением можно отменить случайное изменение через историю Elementor.

Инструкция относится к `/obekty/` и десяти страницам объектов, на которые ведёт каталог. Страница «О компании» требует отдельного исправления редактируемости.
