# Как редактировать страницу «Объекты»

1. Откройте WordPress → Страницы → «Объекты» → «Редактировать в Elementor».
2. Для заголовка или названия объекта выберите нужный заголовок и измените поле «Заголовок».
3. Для описания выберите текстовый виджет и измените его текст. Вставляйте текст без чужого форматирования.
4. Для замены фотографии выберите изображение → «Выбрать изображение» → медиатека.
5. Перед сохранением проверьте страницу в режимах компьютера и телефона, затем нажмите «Обновить» / «Опубликовать».

В структуре страницы карточки подписаны «Объект 1» … «Объект 10», а их поля — «название», «описание», «фотография», «ссылка». Оформление хранится отдельно в HTML-виджете «Оформление каталога». Для обычных изменений текста и фото этот виджет открывать не нужно.

Редактируйте страницу через Elementor: стандартный редактор WordPress не показывает её отдельные виджеты. При случайном удалении блока используйте историю Elementor и восстановите предыдущую версию.

Изменение относится только к `/obekty/`. Страница «О компании» требует отдельного исправления редактируемости.
